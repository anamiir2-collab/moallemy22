# مُعلّمي | Moallemy

نظام إدارة تعليمي متكامل للمدرسين — إدارة الطلاب والمجموعات والحصص والحضور والدرجات والواجبات والمدفوعات والتقارير، مع **تحليل أداء محلي** وتقارير احترافية لولي الأمر.

> الإصدار 2.0.0 — تطوير شامل للإصدار 1.0.0 مع الحفاظ الكامل على كل الوظائف والبيانات السابقة (نظام ترحيل تلقائي).

## المميزات

### الأساس
- **عربي بالكامل + RTL** — تصميم أصلي من اليمين لليسار بخط Cairo
- **Mobile First** — مصمم للهاتف أولًا (360px+) ثم التابلت والديسكتوب
- **PWA** — قابل للتثبيت كتطبيق مع دعم **Offline كامل** (يشمل الخطوط وChart.js)
- **بدون Backend** — يعمل بالكامل في المتصفح، وجاهز للربط بخادم مستقبلًا
- **وضع داكن/فاتح** + أمان PIN + تحصين XSS (escapeHTML على كل البيانات المعروضة)

### التحليل الذكي (محلي - بدون API Keys)
- **محرك الاتجاه (Trend Engine)**: `improving / stable / declining` مع `change` و`confidence` — لا يعتمد على نتيجة واحدة (يفرض درجتين+ ويثق بحجم العينة)
- **مؤشر الأداء العام**: أوزان قابلة للتعديل من الإعدادات (افتراضي: اختبارات 50%، واجبات 20%، حضور 10%، تقييم مستمر 20%) — المكونات الناقصة تُستبعد وتُعاد الموازنة تلقائيًا
- **مولدات**: تحليل الطالب، خطة التحسين، توصيات المدرس، تقرير ولي الأمر، رسالة واتساب
- **مبدأ صارم**: لا يُخترع أي رقم — ما لا توجد بياناته يظهر "غير متوفر" + تنويه بأن التحليل مؤشر أولي وليس حكمًا نهائيًا
- **واجهة Providers**: `AIProviders.local` (افتراضي) + `AIProviders.cloud` (هيكل جاهز — الاتصال يكون عبر endpoint من إعدادات الخادم فقط، **ممنوع وضع مفاتيح API في الفرونت**)

### خصوصية تقرير ولي الأمر (ملزمة)
- لا يعرض بيانات طلاب آخرين أو ترتيبًا
- لا يعرض الملاحظات الداخلية للمدرس
- لا يعرض البيانات المالية
- النص **قابل للتعديل يدويًا** قبل الحفظ أو الإرسال — المدرس صاحب القرار
- الإرسال عبر واتساب: **معاينة ← نسخ اختياري ← تأكيد صريح ← فتح واتساب** (لا إرسال تلقائي أبدًا)

### النسخ الاحتياطي وحماية البيانات
- **Data Versioning**: `meta.dataVersion` + نظام Migrations يرقّي البيانات القديمة تلقائيًا (v1→v2 يوحّد حالات الحضور والحصص ويُثري الدرجات)
- **تصدير JSON** كامل مع Metadata (الإصدار، التاريخ، عدادات المحتوى)
- **استيراد بتحقق مزدوج**: معاينة محتوى الملف ← اختيار **دمج** أو **استبدال** ← تأكيد نهائي
- تصدير الطلاب CSV + تذكير تلقائي إذا مضى أسبوع بدون نسخة + سجل نشاط (Audit Log)

## التشغيل والنشر

### النشر على GitHub Pages
1. ارفع محتويات المشروع إلى مستودع GitHub
2. Settings → Pages → Branch: `main` / Folder: `/root`
3. التطبيق سيعمل على `https://<username>.github.io/<repo>/`

### التشغيل محليًا
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```
> ملاحظة: افتح من `localhost` أو HTTPS — الـ Service Worker لا يعمل على `file://`

## ربط AI API مستقبلًا (نمط آمن)

المعمارية تفصل تجهيز البيانات عن التوليد:

```
AIAnalysis.prepare(studentId)   →  payload موحد
        ↓
AIProviders.cloud.analyze(payload)  →  POST إلى endpoint خاص بك
        ↓
AI.generateStudentAnalysis()    →  يعيدها بصيغة موحدة للواجهة
```

- لا تضع أي مفتاح API في ملفات الواجهة أبدًا
- أنشئ Proxy صغير على خادمك يحمل المفتاح ويستقبل `{task, payload}` ويعيد `{text}`
- حدد الـ endpoint في `meta.aiEndpoint` (من الخادم)، وسيعمل `AIProviders.cloud` تلقائيًا مع fallback للمحلي
