# أداة مزامنة المناهج الرسمية | moe-sync

تقرأ بيانات الكتب الرسمية من بوابة وزارة التربية والتعليم المصرية وتجهّزها لتطبيق مُعلّمي.

## البنية المعمارية

```
بوابة الوزارة (studentbooks.moe.gov.eg)
        ↓  أداة المزامنة هذه (مرة واحدة أو دوريًا)
Supabase (جداول curriculum_*)
        ↓  التطبيق يقرأ من هنا فقط
تطبيق مُعلّمي
```

التطبيق **لا يتصل بموقع الوزارة إطلاقًا** — لا CORS ولا حجب.

## ملاحظة الحجب الجغرافي

موقع الوزارة يستخدم حاجزًا جغرافيًا (Azure WAF) يرفض الطلبات من خارج مصر:

| الوضع | يعمل من مصر | يعمل من أي مكان |
|-------|:---:|:---:|
| `--fetch` (قراءة البوابة) | ✅ | ❌ (403) |
| `--verify` (فحص روابط PDF) | ✅ | ✅ (خوادم الملفات متاحة عالميًا) |
| `--push` (رفع إلى Supabase) | ✅ | ✅ |
| `--import` (ملف محفوظ) | ✅ | ✅ |

> لدى مُعلّمي نسخة كتالوج مدمجة حقيقية (العام 2025-2026 — 249 كتابًا) تعمل فورًا بدون أي مزامنة.
> أداة المزامنة للتحديث المستقبلي عند إضافة الوزارة كتبًا أو أعوامًا دراسية جديدة.

## خطوات التفعيل الكاملة (مرة واحدة)

### 1) تنفيذ مخطط قاعدة البيانات
في لوحة Supabase → SQL Editor، نفّذ:
```
supabase/curriculum-schema.sql
```
(يضيف جداول جديدة فقط — لا يمس أي جدول موجود)

### 2) قراءة الكتالوج الرسمي
من جهاز داخل مصر (أو VPN):
```bash
node tools/moe-sync/moe-sync.js --fetch
```
سيُحدّث `data/moe-catalog.json` و `data/moe-catalog.js`.

### 3) الرفع إلى Supabase
```bash
export SUPABASE_URL="https://secejwjzxfjgjozpteld.supabase.co"
export SUPABASE_SERVICE_ROLE_KEY="مفتاح_الخدمة_السري"
node tools/moe-sync/moe-sync.js --push
```
> مفتاح الخدمة تجده في: Supabase Dashboard → Settings → API → `service_role`
> ⚠️ **لا تضع هذا المفتاح في كود الواجهة أبدًا** — يُستخدم هنا فقط في الطرفية.

### 4) التحقق من الروابط (اختياري)
```bash
node tools/moe-sync/moe-sync.js --verify
```

## التحديث التلقائي المستقبلي

عند إعلان الوزارة كتب العام الدراسي الجديد:
1. شغّل `--fetch` (يكتشف الكتب الجديدة تلقائيًا — لا أسماء مكتوبة يدويًا)
2. شغّل `--push`
3. التطبيق يعرض الكتب الجديدة فورًا، **ولا يحذف كتب السنوات القديمة** (upsert فقط)

## سجلات التحديث

كل كتاب يحمل `last_synced_at` و `source_url`، وجدول `curriculum_sync_state` يوثق آخر مزامنة عامة (يظهر داخل التطبيق في صفحة المناهج).
